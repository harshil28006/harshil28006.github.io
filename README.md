# Harshil Chauhan — Portfolio Website

A minimalist, high-performance personal portfolio website inspired by the visual aesthetic of [raaulc.com](https://www.raaulc.com/).

Built for **Harshil Chauhan**, B.Tech Mechanical Engineering undergraduate at the **National Institute of Technology, Durgapur**.

---

## ⚡ Key Highlights & Architecture

- **Visual Aesthetic**: Inspired directly by `raaulc.com` with clean typography (`JetBrains Mono` + `Inter`), structured spacing, hairline dividers, and zero heavy cards or bloated frameworks.
- **Terminal Motifs**:
  - Top navigation breadcrumb: `~/harshil`
  - Simulated terminal prompt: `$ whois harshil-chauhan`
  - Core stack block: `$ cat core_stack.txt` (ROS 2, Gazebo Harmonic, ArduPilot, MATLAB/Simulink, Python, AWS, Snowflake, DBT)
- **Fast & Pure Vanilla**: 0 npm dependencies, pure HTML5, vanilla CSS, and lightweight JS.
- **Dark / Light Theme Toggle**: Seamless mode switching (`◐` icon in navbar or press `T` on your keyboard) with preference saved in `localStorage`.
