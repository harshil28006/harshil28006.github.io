Autonomous Underwater Vehicle Navigation System

Marine Robotics Simulation & Perception
ROS 2 Gazebo Harmonic ArduPilot OpenCV Python
  • Built an AUV simulation framework using ROS 2, Gazebo Harmonic, and ArduPilot to evaluate autonomous navigation and vehicle dynamics in virtual aquatic environments.
  • Integrated OpenCV path detection and guidance commands for autonomous waypoint following and underwater feature tracking.
  • Designed and validated cascaded PID depth and trajectory control under varying simulated hydrodynamic conditions and turbulence.
  • Implemented ROS 2 nodes for sensor data processing, vehicle thruster control, and inter-node communication across camera, DVL, and sonar sensor topics.
